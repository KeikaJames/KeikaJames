### 👋 Hi there

**PAY MORE ATTENTION TO WHAT U WANT TO DO**

Some of this work is written in places not especially optimized for productivity: ski resort hotels, hot coffee nearby, fewer reasons to rush. ⛷️☕️  
This has not improved the code, but it has occasionally improved the decisions.Most repositories here are exploratory or infrastructural.  
They exist to test assumptions, surface failure modes, and occasionally confirm that stopping early was the right choice.

A lot of people are building impressive things with vibe coding. I get the excitement tools are getting insanely powerful.
But personally, I still think understanding the logic behind what you build matters. If we stop caring about how systems actually work, engineering slowly turns into superstition.
Especially when people start talking about “silicon life” or treating models like mystical beings.
GitHub shouldn’t feel like a theology community to me. It should stay a place for curious people who question things, test things, and understand things materially and dialectically.
